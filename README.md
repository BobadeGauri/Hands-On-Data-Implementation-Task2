# Task 2 — Hands-On Data Lab Implementation (Improved)

## Project overview
This project demonstrates data inspection, cleaning, transformations, descriptive statistics, aggregation, correlation analysis and six visualizations using a reproducible synthetic retail-sales dataset.

## Files
- `task2_data_lab.py`: reproducible Python source code
- `retail_sales_raw.csv`: raw practice dataset with intentional data quality issues
- `retail_sales_cleaned.csv`: cleaned dataset
- `Task2_Hands_On_Data_Lab_Report.docx`: expanded report with tables, code snippets, charts and interpretations
- `task2_submission_description.txt`: 200+ word submission description
- `outputs/`: generated quality/statistics/summary tables
- `plots/`: six charts

## Run
Install dependencies: `pip install pandas numpy matplotlib`
Run: `python task2_data_lab.py`

## Data and ethics note
The data is synthetic, created for learning, and is not real business/customer data. Any currency symbol in chart labels is illustrative only.
