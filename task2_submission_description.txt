This submission presents a reproducible hands-on data science lab using a synthetic retail sales dataset created for educational practice. The project demonstrates dataset inspection, data cleaning, data manipulation, descriptive statistics, correlation analysis, feature engineering, aggregation and visualization. The dataset includes order identifiers, order dates, product categories, sales regions, quantities, unit prices and sales values. Deliberate data quality issues include missing values, duplicate rows, inconsistent capitalization and extra spaces, and a non-numeric price entry.

The Python implementation uses Pandas for CSV loading, DataFrame inspection, type conversion, missing-value checks, duplicate detection, grouping, aggregation and export. NumPy supports numerical processing, and Matplotlib creates visualizations. Data cleaning converts dates and numeric columns to suitable types, standardizes text, removes exact duplicate rows, imputes missing numeric values using medians, and imputes missing categorical values using modes. Sales are recalculated as quantity multiplied by unit price to maintain consistency. Additional features include a month field and revenue bands.

The analysis includes before-and-after data-quality checks, descriptive statistics for quantity, unit price and sales, product-wise and region-wise performance tables, and a correlation matrix. Six visualizations present product sales, regional sales, daily sales trends, order-sales distribution, correlations and sales by revenue band. Each visualization is interpreted in the report, and the code is included so the analysis can be reproduced. Since the data is synthetic, results should be treated as an instructional example rather than a claim about a real business. The project can be extended with pivot tables, dashboards, forecasting and predictive modeling.
